Privacy Architecture & Data Rights

1. Zero Permanent Resume File Retention:

Uploaded PDF and DOCX files are extracted directly into memory and deleted from the filesystem immediately after parsing.

2. External AI Processing Notice:

When live Gemini mode is enabled, parsed text is passed securely over TLS to Google's Gemini API for semantic evaluation. In Academic Demo Mode, no external network requests are dispatched.

3. SQLite Persistence Scope:

Your local database (instance/resumeiq.db) stores only the structured analysis results (scores, matched skills, bullet rewrites) to enable history review and multi-job comparisons.

4. Data Purge & Right to be Forgotten:

You can delete any individual analysis report or wipe all records permanently at any time.

Danger Zone: Complete Data Purge

Permanently wipes all saved evaluations, scores, and bullet rewrites from your local database.
